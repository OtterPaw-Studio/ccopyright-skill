`ccopyright-qa` 是一个只读的软著登记答疑 Skill。它帮助你理解普通计算机软件著作权登记的字段、材料、条件分支和自助路径，也可以中立拆解你提供的脱敏服务报价。

它的目标不是证明所有第三方服务都没有价值，而是让你知道：什么是官方事项，什么可以自己完成，付费服务具体替你做了什么，以及哪些问题确实需要人工专业判断。

## 适合什么问题

| 你的问题 | 你会得到 |
|---|---|
| “通常要准备什么材料？” | 直接答案、法规基线、当前门户待核对项和自助下一步 |
| “前后各连续 30 页是什么意思？” | 具体官方依据、访问日期、适用条件和不确定项 |
| “我一定要找代理吗？” | 官方事项、自助工作、人工服务可能增加的价值与边界 |
| “这份报价具体包含什么？” | 对脱敏报价的交付物、条件、遗漏工作和追问清单 |

如果目标是扫描代码仓库、选择源码、制作说明书、生成 PDF 或校验材料，请改用 `ccopyright-register`。加载本 Skill 不会授权任何仓库写入。

一次完整回答会尽量包含：**直接结论 → 依据类型与日期 → 适用条件 → 不确定项 → 自助下一步 → 相关的付费协助范围**。简单事实题不会被强行扩写成长模板。

## 快速上手

### 1. 安装答疑 Skill

~~~bash
npx skills add OtterPaw-Studio/ccopyright-skill --skill ccopyright-qa
~~~

如果还希望从代码仓库生成材料，可以一次安装两个 Skill：

~~~bash
npx skills add OtterPaw-Studio/ccopyright-skill \
  --skill ccopyright-qa ccopyright-register
~~~

从本地克隆的仓库安装：

~~~bash
npx skills add . --skill ccopyright-qa
~~~

### 2. 直接提问

~~~text
使用 $ccopyright-qa 告诉我申请软件著作权通常要准备哪些材料。
请区分法规基线、当前门户仍需核对的事项，以及我可以自行完成的工作。
~~~

~~~text
使用 $ccopyright-qa 解释“前后各连续 30 页”是什么意思。
请给出官方依据和核对日期，不要开始生成文件。
~~~

~~~text
使用 $ccopyright-qa 帮我拆解下面这份已经脱敏的服务报价。
告诉我每一项交付物、我仍需完成的工作，以及需要向服务商问清楚的问题。
~~~

## 前置依赖

普通答疑只需要支持 Agent Skills 的 AI Agent。它不要求 Python、Chrome、Poppler、
代码仓库或软著门户账号。

问题涉及当前费用、办理入口、表单、上传限制、时限或第三方服务时，Agent 需要
能够访问相应的当前官方页面；无法访问时，Skill 会把结论标记为未核验，而不是
使用记忆中的旧值。

## 可以问什么

- 软件全称、简称、版本和完成日期应如何理解；
- 原创/修改、开发方式、权利取得和权利范围有什么区别；
- 普通申请由哪些主要材料构成；
- 程序和文档鉴别材料的法规基线；
- 合作、委托、下达任务、修改或继受取得可能涉及哪类证明；
- 当前问题是否适合自助，人工服务可能增加什么价值；
- 一份脱敏报价中包含了哪些交付物和待确认承诺；
- 下一步应继续核对官方要求，还是进入材料准备。

如果你要求扫描代码仓库、选择源码、制作说明书、生成 PDF 或校验材料，应该改用
`ccopyright-register`。

## 回答如何核验

回答会尽量区分四类依据：

1. 官方法律、条例或规章，并说明能证明的规则范围；
2. 中国版权保护中心的具体办事指南或 FAQ，并给出访问日期；
3. 本次申请中明确核对或提供的当前门户脱敏原文；
4. 只能证明第三方自身说法的材料，或明确标注的推断/实践建议。

Skill 内置了[官方页面来源目录](references/zh-CN/official-sources.md)，把法规、
申请须知、办理步骤、所需文件、填写说明、审查流程、办理时限、FAQ 和费用通知
分别链接到具体官方页面。页面没有展示发布日期时，只记录实际访问日期。

`ccopyright-register` 的字段和字数门禁是门户兼容性校验配置，不是答疑证据或永久
规则。QA 可以解释它会检查什么，但会明确标注“本地校验值，提交前以当前门户
为准”。

## 如何看待代理与服务费

Skill 不会直接判断某个价格“值”或“不值”。它会先拆分：

- 官方要求的材料和动作；
- 你能够自己完成的事实确认、材料整理和门户操作；
- 服务商提供的整理、文案、排版、录入、沟通或提醒；
- 权属争议、复杂合同、例外交存或涉密等需要专业判断的情形；
- “加急”“包过”“不成功退款”等承诺中尚未定义的范围和条件。

服务商页面只能证明该服务商在某日展示过相应内容，不能自动代表市场价或官方
要求。除非你明确要求当前市场调查，否则 Skill 只分析你提供的脱敏报价。

## 从答疑进入材料准备

当你决定自助准备时，可以这样继续：

~~~text
使用 $ccopyright-register 评估这个仓库是否适合普通软著登记。
先只扫描并列出候选登记边界、缺失事实和全部警告，不要生成材料。
~~~

`ccopyright-register` 会在说明写入范围后，使用 `.ccopyright/` 工作区生成底稿、
源码/文档材料和校验产物。加载 `ccopyright-qa` 本身不会授权任何文件写入。

## 安全与边界

这个 Skill：

- 不扫描或修改代码仓库，不生成申请材料；
- 不填写、提交、签署或支付网页申请；
- 不操作账号，不跟踪进度，不解析补正通知；
- 不判断权属、合同效力或保证登记通过；
- 不维护服务商价格排行榜，也不凭记忆报告当前价格；
- 不收集身份证号、证件扫描件、签名、账号凭据、支付信息或会话数据；
- 不处理例外交存、封存、涉密或军用流程。

对于复杂权属、合同争议或特殊交存，Skill 会说明限制并建议寻找合格的人工专业
支持。所有回答均为信息与材料准备辅助，不构成法律意见。

## 常见问题

### 它会直接告诉我是否应该找代理吗？

它会帮助你判断工作范围和复杂度，但不会替你做价值选择。你会看到哪些是官方
事项、哪些可以自行完成、服务商实际提供什么，以及仍有哪些风险或未知条件。

### 可以上传服务合同让它审查吗？

它可以拆解已经脱敏的服务说明和交付范围，但不判断合同效力。请先删除身份、
订单、付款、账号和签名信息；涉及合同权利义务时应咨询合格专业人士。

### 内置答案一定是最新的吗？

不一定。法规可能修订，办事页面和门户也会变化。涉及当前费用、表单、入口、
时限或上传限制时，应重新核对来源目录中的具体官方页面和本次门户；内置校验值
不能替代这一步。

### 它能替我生成源码和说明书吗？

不能。请安装并使用 `ccopyright-register`。
