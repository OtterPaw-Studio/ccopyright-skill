# Q&A topic map

First determine whether the user wants to understand something or begin
material work. Read only the references needed for the current question.

| Question | Read first | Handling |
|---|---|---|
| Form field, term, or ordinary material | `official-sources.md`, `registration-baseline.md` | Choose a specific official page and distinguish the rule from the current portal |
| Current fee, timeline, channel, or upload limit | `official-sources.md`, `source-policy.md` | Find a current official direct page or mark the value unverified |
| Whether an agency is needed or valuable | `answering-guide.md` | Separate official work, self-service work, convenience, and specialist judgment |
| User-supplied quote or package | `answering-guide.md`, `source-policy.md` | Redact first; analyze this quote only and do not infer a market price |
| Ownership, cooperation/commission, modification, or succession | `official-sources.md`, `registration-baseline.md`, `answering-guide.md` | Explain proof categories without deciding ownership or contract effect |
| Ordinary source/document pages and rows | `registration-baseline.md` | Explain the rule baseline and note that current upload rules still need checking |
| Exceptional deposit, sealing, classified, or military material | `answering-guide.md` | Stop the ordinary path and suggest specialist support |
| Scan a repository, generate, or validate materials | No more QA reference needed | Route to `ccopyright-register` |

## Combined questions

If the user asks both “what is the rule?” and “generate it for me,” first answer
enough to support an informed choice. Explain that preparation writes to the
repository and requires agreement before using `ccopyright-register`. A Q&A
request does not implicitly authorize file writes.

## Common ambiguities

- “What do I need for registration?” can request a checklist or actual
  generation. Inspect the verb and context.
- “Review this quote” means the supplied redacted text by default; do not
  automatically research the provider.
- “How much/how long is it now?” is current-state research; do not use an old
  bundled value.
- “Who owns this software?” asks for an ownership determination and cannot be
  concluded by this Skill.
