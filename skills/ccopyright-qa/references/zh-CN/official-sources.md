# 官方页面来源目录

最后人工核对：2026-09-01

本目录帮助答疑时找到能直接支撑结论的官方页面。它不是网页镜像，也不保证页面
内容以后不变。中国版权保护中心下列办事页面未见明确的页面发布日期或更新日期，
因此这里只记录实际访问日期，不把 HTTP 元数据当作内容发布日期。

## 官方法规与规章

| 来源 | 适合回答 | 时效说明 |
|---|---|---|
| 全国人大：[《中华人民共和国著作权法》](https://www.npc.gov.cn/c2/c30834/202011/t20201119_308796.html) | 著作权制度上位法问题 | 使用页面公布文本，并核对是否有后续修法 |
| 国家行政法规库：[《计算机软件保护条例》现行整合文本（含 2011、2013 年修订）](https://xzfg.moj.gov.cn/mobile/law/detail?LawID=581) | 软件著作权保护、权利归属等法规框架 | 复杂权属仍需专业判断 |
| 国家版权局：[《计算机软件著作权登记办法》](https://www.ncac.gov.cn/xxfb/flfg/bmgz/202410/t20241015_869486.html) | 登记主体、主要材料、鉴别材料、一般/例外交存、证明文件、A4 等 | 普通登记材料的主要规则基线 |

法规能证明制度和材料基线，但不自动证明当前门户字段、上传限制、证书安排或实际
办理展示。

## 如何选择依据

- 问“法律或材料规则是什么”：优先法规、条例或登记办法。
- 问“官网现在怎么操作”：优先相应办事指南和当前登录后门户。
- 问“字段怎么理解”：先用填写说明，再核对当前表单原文。
- 问“多久、多少钱、证书怎么发”：必须使用当前官方页面并写明访问日期。
- 问第三方套餐：官方来源只用于区分官方事项；套餐范围和价格由该服务商的当前
  脱敏材料证明。

## 与门户校验配置的关系

`ccopyright-register` 中的字段、条件分支和字数门禁属于门户兼容性配置，不属于本
目录的官方依据。QA 可以说明该配置当前检查什么，但必须标注“内置校验值，提交前
以当前门户为准”；不能仅凭配置把一个数值表述成现行官方规则。
