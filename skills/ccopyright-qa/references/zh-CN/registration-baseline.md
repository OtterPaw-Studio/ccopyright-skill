# 普通软著登记答疑基线

最后核对日期：2026-09-01

## 主要官方来源

- 国家版权局：[《计算机软件著作权登记办法》](https://www.ncac.gov.cn/xxfb/flfg/bmgz/202410/t20241015_869486.html)
- 中国版权保护中心：[软件登记办事指南入口](https://www.ccopyright.com.cn/index.php?optionid=1030)
- 本 Skill：[官方页面来源目录](official-sources.md)

法规页面是本文件中普通登记材料基线的依据。官网当前表单、办事入口、费用、模板
和上传要求需要在每次相关答疑时重新核对。

## 法规能够直接支持的普通基线

- 软件登记机构为中国版权保护中心；
- 申请软件著作权登记的主体应当是软件著作权人，或者通过继承、受让、承受取得
  软件著作权的自然人、法人或其他组织；
- 申请登记的软件应是独立开发的软件，或者经原著作权人许可、在功能或性能方面
  有重要改进的修改软件；
- 主要申请材料包括按要求填写的申请表、软件鉴别材料和相关证明文件；
- 鉴别材料包括程序和文档；普通基线为源程序和任一种文档的前、后各连续 30 页，
  不足 60 页时提交全部；除规定情形外，程序每页不少于 50 行，文档每页不少于
  30 行；
- 条件证明可能包括身份证明、权属合同或项目任务书、原著作权人许可，以及继承、
  受让或承受证明；
- 申请表使用中文，外文证明附中文译本，申请文件使用 A4 纸张；
- 法规另设例外交存和封存，不属于本项目普通材料生成流程。

回答时应链接到具体法规条文，不要只写“官方规定”。

## 法规没有证明的事项

上述法规不能单独证明当前：

- 在线门户的全部字段和选项；
- 账号、实名认证或电子签署操作；
- PDF 文件大小、命名或上传数量；
- 官方收费项目或金额；
- 当前实际办理时长、证书形式或领取方式；
- 任一服务商的价格、交付范围、成功率或加急能力。

这些问题应读取来源目录中的具体当前官方页面，或本次明确提供并脱敏的当前门户
原文。

## 关于是否必须购买第三方服务

上述法规把申请表、鉴别材料和相关证明文件列为主要材料，没有把购买第三方服务
列为申请材料。由此只能说明“代理服务本身不是这份法规列出的材料”，不能据此
保证每位申请人都适合完全自助，也不能评价某项人工服务是否值得购买。

答疑时应继续拆分：用户需要完成的官方事项、用户能否自行完成、服务商实际提供
的劳动，以及复杂权属或特殊流程是否需要人工专业支持。

## 门户校验配置不是官方依据

配置 ID：`ccpc-form-profile-v1`

配套的 `ccopyright-register` 使用下列精简配置提前发现填写问题。QA 可以解释“本地
当前会检查什么”，但该配置不属于官方来源；回答数值时必须同时说明“内置校验值，
提交前以当前门户为准”。

配置覆盖软件全称/可选简称/版本、权利取得和范围、软件分类、原创/修改、开发方式、
完成与发表、六项环境、语言、源程序量、用途、行业、主要功能、技术特点、普通/
例外交存、著作权人和共同享有选择。

| 配置字段 | 本地门禁 |
|---|---:|
| 修改、合成或翻译说明 | 最多 50 字符 |
| 六个环境字段 | 每项最多 50 字符 |
| 其他编程语言 | 最多 120 字符 |
| 开发目的 | 最多 50 字符 |
| 面向领域/行业 | 最多 50 字符 |
| 软件主要功能 | 500～1300 字符 |
| 其他技术特点 | 最多 100 字符 |

条件分支包括：已发表时填写首次发表日期/国家/地区；修改软件填写说明和依据；
合作、委托或下达任务开发核对相应协议/任务文件；多个著作权人与共同享有选择
保持一致；程序和文档例外交存停止普通流程。

配置尚未建立 PDF 大小/命名/方向/上传数量、完整帮助文字、继受取得和部分权利的
全部动态字段、例外交存细节及后续确认/签章页面。这些数值和分支必须通过具体官方
页面或申请人本次看到的门户确认。
