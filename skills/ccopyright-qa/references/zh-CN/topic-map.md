# 答疑主题路由

先确定用户究竟想“了解”还是“开始做材料”。只读取当前问题需要的参考文件。

| 问题类型 | 先读 | 处理方式 |
|---|---|---|
| 表单字段、术语、普通材料 | `official-sources.md`、`registration-baseline.md` | 选择具体官方页，解释法规与当前门户的区别 |
| 当前费用、时限、入口、上传限制 | `official-sources.md`、`source-policy.md` | 必须找当前官方直达页，找不到就标记未核验 |
| 是否需要代理、服务是否值得 | `answering-guide.md` | 拆分官方事项、自助工作、人工便利和专业判断 |
| 用户提供的报价或套餐 | `answering-guide.md`、`source-policy.md` | 先脱敏，只分析这份报价，不推断市场价 |
| 权属、合作/委托、修改或继受取得 | `official-sources.md`、`registration-baseline.md`、`answering-guide.md` | 解释证明类别，不作权属或合同结论 |
| 普通源码/文档页数与行数 | `registration-baseline.md` | 说明法规基线，并提示当前上传规则仍需核对 |
| 例外交存、封存、涉密或军用 | `answering-guide.md` | 停止普通流程并建议专业支持 |
| 扫描仓库、生成或校验材料 | 无需继续加载 QA 参考 | 路由到 `ccopyright-register` |

## 组合问题

如果用户同时问“规则是什么”和“帮我生成”，先回答足以支持选择的规则，再明确
说明准备工作会写入仓库，需要用户同意后使用 `ccopyright-register`。不要让答疑
请求隐式授权文件写入。

## 常见消歧

- “软著需要什么？”可能是在问材料清单，也可能是在问让 Agent 生成材料。先判断
  动词和上下文。
- “帮我看看报价”默认只分析用户给出的脱敏文字，不自动搜索服务商。
- “官网现在多少钱/多久？”是时效问题，不使用内置旧值。
- “这个软件属于谁？”是权属判断，不能由本 Skill 下结论。
