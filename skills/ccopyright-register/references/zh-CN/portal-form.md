# 门户表单校验配置（中文）

配置 ID：`ccpc-form-profile-v1`

## 定位与边界

本文件记录在产品设计阶段从登记表单操作路径中提取的字段、选项、条件分支和界面
计数限制。它是用于提前发现填写问题的门户兼容性配置，不是官方来源、法律规则或
截图证据库；Skill 不随附原始表单图片，也不保留附件接收历史。

最终生成前仍须依据[当前官方来源](official-sources.md)和申请人实际看到的门户更新
`facts/application.json` 中的 `requirements`，填写真实的
`requirements.captured_at`，并由申请人确认
`confirmations.requirements.current`。当前门户与本配置冲突时，以本次核对结果为准。

## 配置字段与选项

- 权利取得方式：`original`（原始取得）或 `successor`（继受取得）。
- 软件全称：必填；软件简称：可选，无简称时留空，不填写“无”；版本号：必填。
- 权利范围：`all`（全部权利）或 `partial`（部分权利）。
- 软件分类：`application`、`embedded`、`middleware`、`operating-system`。
- 软件说明：`original`（原创）或 `modified`（修改，含翻译软件、合成软件）。
- 开发方式：`independent`、`cooperative`、`commissioned`、`assigned-task`。
- 开发完成日期与发表状态；已发表时显示首次发表日期、国家和地区。
- 六个环境字段：开发硬件、运行硬件、开发操作系统、开发工具、运行平台/操作系统、运行支持环境/支持软件。
- 编程语言、源程序量、开发目的、面向领域/行业、软件主要功能。
- 软件技术特点标签及其他技术特点。配置标签包括 APP、游戏、教育、金融、医疗、地理信息、云计算、信息安全、大数据、人工智能、VR、5G、小程序、物联网、智慧城市。
- 程序和文档分别选择一般交存或例外交存。
- 著作权人列表，以及是否由多个著作权人共同享有软件著作权。

## 内置校验门禁

| 字段 | 配置限制 |
|---|---:|
| 修改、合成或翻译说明 | 50 字符 |
| 六个环境字段 | 每项 50 字符 |
| 其他编程语言 | 120 字符 |
| 开发目的 | 50 字符 |
| 面向领域/行业 | 50 字符 |
| 软件主要功能 | 界面显示 500–1300 字符 |
| 其他技术特点 | 100 字符 |

`500–1300` 是内置兼容性门禁，仍应在当前门户确认帮助说明和实际校验行为。该配置
没有建立“源程序量”的官方统计口径；默认使用所选第一方源码的物理行数，申请人
也可以明确采用经确认的软件总行数。

草稿生成把超出上下限的问题列为 `WARNING`；最终生成会阻断，直到申请人修正值或
依据当前门户更新配置。最小值只约束已经填写的文本，不会单独把可选字段变成必填
字段；字段是否必填由基础字段和下列条件分支另行决定。

## 条件分支

- `published`：要求首次发表日期、国家和地区；`unpublished` 不要求。
- `modified`：要求 50 字内说明，并选择已经登记或需要原权利人授权的依据。
- `successor`：要求填写继受取得说明；具体类型和证明仍按当前门户核对。
- `partial`：要求填写部分权利说明；具体权利选项仍按当前门户核对。
- `cooperative`：配置要求核对合作开发合同或协议 PDF。
- `commissioned`：配置要求核对委托开发合同或协议 PDF。
- `assigned-task`：配置要求核对项目任务书或证明权属的合同 PDF。
- 多个著作权人：事实文件中的名称列表必须与共同享有选项一致。
- 程序一般交存：配置为源程序前连续 30 页和后连续 30 页，PDF。
- 文档一般交存：配置为任何一种文档的前连续 30 页和后连续 30 页，PDF；可增加其他文档。
- 其他相关证明文件：配置允许记录多个 PDF 准备项。

未满足的条件字段和活动分支的证明准备状态会在草稿中显示为 `WARNING`，并阻断
最终生成。证明文件仍保存在仓库外，事实文件只记录有限状态。Skill 不生成例外交存
材料；选择程序或文档例外交存时，停止普通流程并转入专业处理。

## 尚未确认

- PDF 单文件大小、文件名、页方向和上传数量限制；
- 问号帮助提示的完整文字；
- 继受取得、部分权利的完整动态字段；
- 例外交存的当前门户要求；
- 后续确认、签章、声明和提交页面；
- 当前门户完整的软件分类、编程语言和技术特点选项。

## 隐私边界

申请底稿只保留材料一致性所需的著作权人规范名称。国家/地区、主体类型和证件类型可以作为人工核对项，但不得在仓库中保存证件号码、身份证明扫描件、未脱敏门户截图、签名、账号或会话信息。条件证明文件只记录外部准备状态，不复制进 `.ccopyright/`。
